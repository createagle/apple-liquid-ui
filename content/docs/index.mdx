欢迎使用 **Apple Liquid UI**。本项目基于 **Next.js + Fumadocs + Tailwind CSS v4 + shadcn/ui (`base-nova`)** 构建，所有组件源码统一维护在 `components/ui/` 中，并自动编译为静态的 shadcn Registry（`/r/*.json`）。

## 通过 shadcn Registry 安装

### 方式一：配置 Namespace（推荐）

在目标项目的 `components.json` 中注册 `@apple-liquid` 命名空间：

```json
{
  "registries": {
    "@apple-liquid": "https://your-domain.com/r/{name}.json"
  }
}
```

随后即可按名称直接安装任意组件：

```bash
npx shadcn@latest add @apple-liquid/button
```

### 方式二：直接通过 URL 安装

```bash
npx shadcn@latest add https://your-domain.com/r/button.json
```

## 本地构建与开发

```bash
# 启动文档开发服务器
pnpm dev

# 仅重新同步 registry.json 并编译 public/r/*.json
pnpm registry:build

# 完整构建（自动编译 Registry + 导出纯静态站点到 out/）
pnpm build
```
