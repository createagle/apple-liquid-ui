基于 `@base-ui/react/switch`、`LiquidLens` 与 `motion/react` 构建，完整还原 **Apple iOS 27** 与 **macOS 27** Liquid Glass 开关的标志性交互体验。

- **按压/拖拽液态水滴折射**：点击切换或**按住滑块左右拖动**时，纯白胶囊滑块会膨胀浮起为透明光学透镜（`LiquidLens`），透视并实时折弯底层轨道与背景，同时随拖动进度连续渐变轨道色彩。
- **速度感应拉伸与弹簧回弹**：结合 Motion `useVelocity` 与 `useSpring`，快速滑动时水滴自然拉伸，松手后按阈值弹性吸附回目标位置。
- **原生视口响应式**：自动按 `< 768px`（iOS 27 宽胶囊 `60×28px` · Apple Green）与 `>= 768px`（macOS 27 紧凑胶囊 `40×22px` · Apple Blue）切换尺寸、默认强调色与弹簧阻尼。

## 使用方式

```tsx
import { Switch } from '@/components/ui/switch';
import { Label } from '@/components/ui/label';

export function Example() {
  return (
    <div className="flex items-center gap-3">
      <Switch id="liquid-mode" defaultChecked />
      <Label htmlFor="liquid-mode">启用液态玻璃</Label>
    </div>
  );
}
```

## Props API

### `Switch`

兼容 `@base-ui/react/switch` `Switch.Root` 的全部标准属性（`checked`、`defaultChecked`、`onCheckedChange`、`disabled`、`readOnly`、`name`、`required` 等），并扩展以下属性：

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `variant` | `'default' \| 'green' \| 'blue' \| 'glass'` | `'default'` | `default` 自动按视口切换（iOS 绿 ↔ macOS 蓝），也可显式指定 `green`、`blue` 或 `glass` 液态玻璃轨道 |
| `size` | `'sm' \| 'default' \| 'lg'` | `'default'` | 响应式尺寸阶梯，移动端与桌面端自动匹配对应触控比例 |
| `showLabels` | `boolean` | `false` | 是否在轨道内显示 Apple 风格无障碍 `I / O` 开关指示符 |
| `refraction` | `number` | `1` | 按压/拖动时 Lip 曲面斯涅耳折射倍率（默认 `1`，可按需微调） |
| `dispersion` | `number` | `0.055` | 液态水滴边缘的微弱 RGB 色散强度（`0` 为关闭色散） |
| `disableMotion` | `boolean` | `false` | 禁用液态透镜折射与弹簧动效（自动尊重 `prefers-reduced-motion`） |
