完全兼容 shadcn/ui 标准 JSX API（`<Drawer>` / `<DrawerTrigger>` / `<DrawerContent>` / `<DrawerHeader>` / `<DrawerFooter>` / `<DrawerTitle>` / `<DrawerDescription>` / `<DrawerClose>`），同时也是本库 `Select`、`Dialog`、`Popover`、`DropdownMenu` 与 `ContextMenu` 在移动端（`< 768px`）的底层手势容器：

- **默认开启液态玻璃折射**：`DrawerContent` 默认挂载独立层 `<LiquidSurfaceBackdrop />`（`glass={true}`），底部滑出时自动应用 `32px` 顶部大圆角与 `openBottom` 无底角折射，且不截断内部 `Switch`、`Slider` 等 `LiquidLens` 子控件的采样。
- **原生手势交互**：内置 Apple 27 风格顶部拖拽手柄（`showSwipeHandle` 默认开启），支持 `swipeDirection="down" | "up" | "left" | "right"` 与 `snapPoints` 多段高度吸附。

## 安装（Shadcn Registry）

```bash
# 通过配置好的 @apple-liquid 命名空间安装（自动关联 liquid-surface 与 liquid-glass）
npx shadcn@latest add @apple-liquid/drawer
```

## Props API

### `Drawer`

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `swipeDirection` | `'down' \| 'up' \| 'left' \| 'right'` | `'down'` | 抽屉滑出与手势关闭方向 |
| `showSwipeHandle` | `boolean` | `true` | 是否显示顶部/侧边拖拽指示手柄 |
| `snapPoints` | `(number \| string)[]` | — | 多段吸附高度点（如 `[0.45, 0.85]`） |
| `modal` | `boolean` | `true` | 是否以模态遮罩模式打开 |

### `DrawerContent`

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `glass` | `boolean` | `true` | 是否启用 Apple 27 液态玻璃光学折射背景；设为 `false` 切换为实体表面 |
| `backdrop` | `React.ReactNode` | — | 自定义底层折射节点（供复合组件覆盖默认参数） |
