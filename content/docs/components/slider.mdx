基于 `@base-ui/react/slider`、`LiquidLens` 与 `motion/react` 构建，还原 **Apple macOS 27** 与 **iOS 27** Liquid Glass 滑块的横胶囊造型与拖动折射效果。

- **拖动液态水滴折射**：按住或拖动胶囊滑块时，白色滑块会弹性膨胀为透明光学透镜（`LiquidLens`），透视并折弯下方蓝色进度轨道与刻度线，松手后顺滑回弹。
- **macOS 原生刻度与区间**：原生支持单值调节、双滑块区间（Range）以及 macOS 系统设置同款等距刻度线（`ticks`）。
- **原生视口响应式**：自动按 `< 768px`（iOS 27 大触控胶囊）与 `>= 768px`（macOS 27 精致胶囊）切换轨道粗细与滑块尺寸。

## 使用方式

```tsx
import { Slider } from '@/components/ui/slider';

export function Example() {
  return <Slider defaultValue={60} min={0} max={100} />;
}
```

## Props API

### `Slider`

兼容 `@base-ui/react/slider` `Slider.Root` 的全部标准属性（`value`、`defaultValue`、`onValueChange`、`min`、`max`、`step`、`orientation`、`disabled` 等），并扩展以下属性：

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `variant` | `'default' \| 'glass'` | `'default'` | `default` 为 Apple System Blue 进度条，`glass` 为控制中心半透明液态玻璃轨道 |
| `size` | `'sm' \| 'default' \| 'lg'` | `'default'` | 响应式尺寸阶梯，移动端与桌面端自动匹配对应触控比例 |
| `ticks` | `boolean \| number` | `false` | 是否显示 macOS 风格等距刻度线，支持传入具体刻度数量 |
| `refraction` | `number` | `1` | 拖动时 Lip 曲面斯涅耳折射倍率（默认 `1`，可按需微调） |
| `dispersion` | `number` | `0.055` | 液态水滴边缘的微弱 RGB 色散强度（`0` 为关闭色散） |
| `disableMotion` | `boolean` | `false` | 禁用液态透镜折射与弹簧动效（自动尊重 `prefers-reduced-motion`） |
