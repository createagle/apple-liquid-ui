完全兼容 shadcn/ui 标准 JSX API（`<Textarea>`），与 `Input` 共享一致的 Apple macOS 27 & iOS 27 视觉与聚焦规范，并默认启用 CSS `field-sizing-content` 随输入内容自然增高：

- **桌面端（`>= 768px` · macOS 27）**：`13px` 字号、`12px` 柔和圆角与 `84px` 默认最小高度。
- **移动端（`< 768px` · iOS 27）**：`16px` 防缩放字号、`16px` 圆角与 `96px` 触控最小高度。
- **默认液态玻璃材质**：默认呈现响应 `--liquid-glass-tint` 的液态玻璃表面，与玻璃 `Button` / `Input` 共用 `Regular - Small` 控件材质（Chromium 内核浏览器中圆角边缘带 SDF 光学折射，Safari / Firefox 自动回退为毛玻璃），传入 `glass={false}` 可切换为实体框；置于玻璃表面内时自动切换为 Over-Glass 凹槽。

## 使用方式

```tsx
import { Textarea } from '@/components/ui/textarea';

export function Example() {
  return <Textarea placeholder="输入你的备注…" />;
}
```

## Props API

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `size` | `'sm' \| 'default' \| 'lg'` | `'default'` | 尺寸与圆角阶梯（含自适应最小高度） |
| `glass` | `boolean` | `true` | 默认开启液态玻璃表面（含边缘光学折射）并响应全局 `--liquid-glass-tint`；传入 `false` 切换为实体文本框 |
| `surface` | `'default' \| 'over-glass'` | 自动检测 | 所处表面语境；在玻璃表面内自动为 `'over-glass'`（关闭玻璃、切换半透明凹槽），传入可强制覆盖 |
