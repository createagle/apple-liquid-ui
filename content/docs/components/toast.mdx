基于 `@base-ui/react/toast` 构建，完全兼容 `Toaster`、`toast`、`createToastManager` 与 `useToastManager` API，默认还原 Apple 27 系统通知横幅体验：

- **桌面端（`>= 768px` · macOS 27）**：默认锚定在右上角（`position="top-right"`），采用 `20px` 圆角液态玻璃卡片，多条通知自动层叠缩放并在悬停时优雅展开。
- **移动端（`< 768px` · iOS 27）**：自动在屏幕顶部居中显示 `24px` 圆角液态玻璃通知横幅，支持上滑或左右滑动快速关闭。

点击按钮连续触发多条通知，悬停在通知卡片上可展开堆叠队列，切换 **桌面 / 移动端** 查看右上角 ↔ 顶部居中的自动适配：

## 安装（Shadcn Registry）

```bash
# 通过配置好的 @apple-liquid 命名空间安装（自动关联 button、liquid-surface 与 liquid-glass）
npx shadcn@latest add @apple-liquid/toast
```

## Props API

### `Toaster`

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `position` | `'top-right' \| 'top-center' \| 'bottom-right'` | `'top-right'` | 通知视口锚定位置（`top-right` 在移动端自动居中） |
| `glass` | `boolean` | `true` | 是否启用 Apple 27 液态玻璃折射材质 |
| `toastManager` | `ToastManager` | 内置全局 `toast` | 可选自定义局部通知管理器（通过 `createToastManager()` 创建） |
