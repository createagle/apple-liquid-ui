完全兼容 shadcn/ui 标准 JSX API（`<Card>` / `<CardHeader>` / `<CardTitle>` / `<CardDescription>` / `<CardAction>` / `<CardContent>` / `<CardFooter>`），按 Apple macOS 27 & iOS 27 视觉规范打造：

- **默认液态玻璃 + 独立背景层**：默认开启 `glass={true}` 并使用独立的 `-z-10` 同级背景层渲染模糊，避免在 Chromium 中形成嵌套 Backdrop Root，确保卡片内部的 `Switch`、`Slider`、`Tabs` 液态水滴折射不受截断。
- **可选真实光学边缘折射**：开启 `refract` 即可挂载 `<LiquidSurfaceBackdrop />`，为卡片边缘提供实时 SDF 折射高光。
- **实体与嵌套分组适配**：传入 `glass={false}` 切换为实体卡片（深色对齐 iOS 27 `#1C1C1E`），嵌套在另一层玻璃表面（玻璃 Card、Dialog、Popover 等）内时自动切换为 Over-Glass（对齐 macOS 27 `Group Boxes` 柔和底色）；玻璃卡片内部的 `Button` / `Input` / `Textarea` 也会自动使用 Over-Glass 样式。

## 使用方式

```tsx
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from '@/components/ui/card';

export function Example() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>iCloud+ 同步</CardTitle>
        <CardDescription>跨设备保持文稿与照片实时一致。</CardDescription>
      </CardHeader>
      <CardContent>已使用 128 GB / 2 TB</CardContent>
    </Card>
  );
}
```

## Props API

### `Card`

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `size` | `'default' \| 'sm'` | `'default'` | 密度与圆角规格（默认 `26px/22px`，`sm` 为 `20px/16px`） |
| `glass` | `boolean` | `true` | 默认开启液态玻璃独立底板；传入 `false` 切回实体卡片 |
| `surface` | `'default' \| 'over-glass'` | 自动检测 | 所处表面语境；嵌套在玻璃表面内时自动为 `'over-glass'`，传入可强制覆盖 |
| `refract` | `boolean` | `false` | 开启 `<LiquidSurfaceBackdrop />` 真实 SVG 边缘光学折射 |
