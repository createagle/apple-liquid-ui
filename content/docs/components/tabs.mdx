基于 `@base-ui/react/tabs`、`@liqui-design/glass` 与 `motion/react` 构建，严格对照 **Apple iOS 27（Segmented Controls / Tab Bars）** 与 **Apple macOS 27（Segmented Controls）** 设计规范。

- **动态液态水滴透镜**：点击切换或**按住滑块左右拖动**时，滑块会浮起为高透光学透镜（`blur: 0`、`dispersion: 0.06`），掠过标签上方时真实放大并折弯底层文字与图标，并随移动速度产生液态拉伸（Squash & Stretch）。
- **原生视口响应式**：无需额外 Provider，自动按 `< 768px`（iOS 27）与 `>= 768px`（macOS 27）切换尺寸、圆角、堆叠方向与弹簧阻尼。

```bash

npx shadcn@latest add @apple-liquid/tabs

# 或直接通过 URL 安装
npx shadcn@latest add https://your-domain.com/r/tabs.json
```

## 悬浮导航栏（Tab Bar：iOS 27 ↔ macOS / iPad 27）

同一个 `variant="tab-bar"` 在不同屏幕宽度下自动切换结构：
- **移动端（`< 768px`）**：iOS 27 标志性的 `62px` 悬浮玻璃胶囊，图标在上、文字在下（`11px`），选中态使用 Apple Blue `#0088FF` / `#0091FF`，支持手指左右滑动擦洗切换。
- **桌面端（`>= 768px`）**：自动舒展为 iPad / macOS 27 风格的 `44px` 横向图标+文字悬浮胶囊导航栏。

## 使用方式

```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from '@/components/ui/tabs';

export function Example() {
  return (
    <Tabs defaultValue="glass">
      <TabsList variant="glass">
        <TabsTrigger value="glass">液态玻璃</TabsTrigger>
        <TabsTrigger value="optics">光学折射</TabsTrigger>
        <TabsTrigger value="motion">弹簧动效</TabsTrigger>
      </TabsList>
      <TabsContent value="glass">内容区域...</TabsContent>
    </Tabs>
  );
}
```

## Props API

### `TabsList`

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `variant` | `'default' \| 'glass' \| 'tab-bar' \| 'line'` | `'default'` | `default` 为分段控制器，`glass` 为悬浮玻璃胶囊，`tab-bar` 为响应式图标导航栏，`line` 为极简下划线 |
| `refraction` | `number` | `28` | 拖动/切换时悬浮液态玻璃水滴的凸透镜折射强度（px） |
| `dispersion` | `number` | `0.055` | 悬浮液态水滴边缘微弱 RGB 光学色散强度（`0` 为纯无色折射） |
| `disableMotion` | `boolean` | `false` | 禁用拖拽擦洗与液态折射透镜动效（自动尊重 `prefers-reduced-motion`） |
