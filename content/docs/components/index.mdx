## Registry 产物

执行 `pnpm registry:build` 后，基础样式包 `liquid-glass` 与所有 `components/ui/*.tsx` 会自动同步到根目录 `registry.json`，并编译为 `public/r/<name>.json`（静态导出时位于 `out/r/<name>.json`）。

- `public/r/registry.json`：完整组件目录清单
- `public/r/liquid-glass.json`：Apple 系统色、`@liqui-design/glass` Token 与 Motion 弹簧预设
- `public/r/button.json`：响应式 Liquid Glass Button
- `public/r/tabs.json`：响应式 Liquid Glass Tabs（自动关联 `@apple-liquid/liquid-lens`）
- `public/r/select.json`：响应式 Select（自动关联 `@apple-liquid/drawer`、`hooks/use-mobile.ts` 与 `@apple-liquid/liquid-glass`）
- `public/r/switch.json`：响应式 Liquid Glass Switch（自动关联 `@apple-liquid/liquid-lens`、`hooks/use-mobile.ts` 与 `@apple-liquid/liquid-glass`）
- `public/r/slider.json`：响应式 Liquid Glass Slider（自动关联 `@apple-liquid/liquid-lens`、`hooks/use-mobile.ts` 与 `@apple-liquid/liquid-glass`）
- `public/r/dialog.json`：响应式 Liquid Glass Dialog（自动关联 `@apple-liquid/drawer`、`@apple-liquid/button`、`hooks/use-mobile.ts` 与 `@apple-liquid/liquid-glass`）
- `public/r/alert-dialog.json`：响应式 Liquid Glass AlertDialog（自动关联 `@apple-liquid/button` 与 `@apple-liquid/liquid-glass`）
