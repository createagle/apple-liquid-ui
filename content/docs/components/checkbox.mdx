完全兼容 shadcn/ui 标准 JSX API（`<Checkbox>`），采用纯 CSS 视口断点（`md:` / `768px`）自动还原双端原生规范：

- **语义统一**：全端保持**圆角方框**造型，与圆形的 `RadioGroup`（单选）形成清晰直觉区分。
- **桌面端（`>= 768px` · macOS 27）**：对齐 Apple macOS 27 UI Kit `3 Rg` 规范，默认 `16×16` 圆角方框（`5px` 圆角），未选中态采用柔和半透明底色与细微内阴影，选中及半选态使用恒定高对比度的 Apple Blue 液态光泽填充。
- **移动端（`< 768px` · iOS 27）**：保持一致的圆角方框形态，自动放大至 `22×22`（`6px` 圆角）并扩展点击热区，单手点按更轻松。
- **半选态与动效**：原生支持 `indeterminate`（居中圆角短横线）与 `motion/react` 弹簧指示器弹出，并自动尊重系统 `prefers-reduced-motion`。

## 液态玻璃材质（Glass）

为未选中态叠加正交 `glass` 属性，即可实时响应左侧边栏的「玻璃通透度」滑块；选中态保持恒定高对比度蓝底以确保壁纸背景上的可读性：

## 使用方式

```tsx
import { Checkbox } from '@/components/ui/checkbox';

export function Example() {
  return (
    <label className="flex items-center gap-2.5">
      <Checkbox defaultChecked />
      <span className="text-sm">自动同步 iCloud 数据</span>
    </label>
  );
}
```

## Props API

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `size` | `'sm' \| 'default' \| 'lg'` | `'default'` | 尺寸阶梯（全端圆角方框：移动 `18/22/26px` ↔ 桌面 `14/16/20px`） |
| `glass` | `boolean` | `false` | 为未选中态叠加响应全局 `--liquid-glass-tint` 的液态玻璃表面 |
| `indeterminate` | `boolean` | `false` | 显示 macOS 27 风格居中短横线半选态 |
| `disableMotion` | `boolean` | `false` | 禁用勾选指示器的弹簧缩放动效 |
