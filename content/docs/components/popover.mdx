完全兼容 shadcn/ui 标准 JSX API（`<Popover>` / `<PopoverTrigger>` / `<PopoverContent>` / `<PopoverHeader>` / `<PopoverTitle>` / `<PopoverDescription>` / `<PopoverClose>`），遵循 Apple 27 官方人机交互规范，通过 `useIsMobile()`（`768px`）自动完成双端形态切换：

- **桌面端（`>= 768px` · macOS 27）**：基于 `@base-ui/react/popover` 锚定在触发元素四周，采用 macOS 27 官方 `20px` 圆角与 `<LiquidSurfaceBackdrop tone="menu" />` 真实边缘折射基座，内部嵌套 `Switch`、`Slider` 等 `LiquidLens` 控件不会产生 Backdrop Root 冲突。
- **移动端（`< 768px` · iOS 27）**：对应官方 UI Kit 中“Popover 仅用于宽屏，紧凑屏自适应 Sheet”的规范，自动切换为贴边 `32px` 顶圆角液态玻璃底部 `Drawer`，支持手势下滑关闭与安全区适配。

## 使用方式

```tsx
import { Button } from '@/components/ui/button';
import {
  Popover,
  PopoverClose,
  PopoverContent,
  PopoverDescription,
  PopoverHeader,
  PopoverTitle,
  PopoverTrigger,
} from '@/components/ui/popover';

export function Example() {
  return (
    <Popover>
      <PopoverTrigger render={<Button variant="secondary">打开设置</Button>} />
      <PopoverContent>
        <PopoverHeader>
          <PopoverTitle>快速设置</PopoverTitle>
          <PopoverDescription>调整当前视图的显示参数。</PopoverDescription>
        </PopoverHeader>
        <div className="flex justify-end gap-2">
          <PopoverClose render={<Button size="sm" variant="default" />}>
            完成
          </PopoverClose>
        </div>
      </PopoverContent>
    </Popover>
  );
}
```

## Props API

### `PopoverContent`

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `side` | `'top' \| 'bottom' \| 'left' \| 'right'` | `'bottom'` | 桌面端气泡相对触发器的弹出方向 |
| `sideOffset` | `number` | `8` | 桌面端气泡与触发器之间的间距（px） |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | 桌面端气泡沿锚点轴线的对齐方式 |
| `alignOffset` | `number` | `0` | 桌面端对齐偏移量（px） |
| `mobileTitle` | `React.ReactNode` | — | 当内容中未包含 `<PopoverTitle>` 时，可选为移动端底部抽屉补充居中标题 |
| `className` | `string` | — | 自定义面板宽度或间距（桌面端默认 `w-80`，移动端自动全宽贴边） |
