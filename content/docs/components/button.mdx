基于 **`@liqui-design/glass`**（真实圆角 SDF 凸透镜置换折射 + 全局 SVG 滤镜注册表，支持 Chrome / Safari / Firefox）、`@base-ui/react/button` 与 `motion/react` 构建，严格对照 **Apple macOS 27 UI Kit** 与 **Apple iOS 27 UI Kit** 规范设计。

无需额外 Provider 或平台参数，组件直接按设备视口宽度（Tailwind `md:` 断点 `768px` 与 `useIsMobile()`）自动切换桌面端与移动端形态。

## 安装（Shadcn Registry）

```bash
# 通过配置好的 @apple-liquid 命名空间安装（自动安装 @liqui-design/glass、motion 并写入相关 CSS Token）
npx shadcn@latest add @apple-liquid/button

# 或直接通过 URL 安装
npx shadcn@latest add https://your-domain.com/r/button.json
```

## 响应式规范：macOS 27 vs iOS 27

采用标准 Tailwind 移动优先断点（`< 768px` 默认 iOS 27，`md:` 及以上自动切换 macOS 27）与 `useIsMobile()` Hook：

| 特性 | macOS 27（桌面端 `>= 768px`） | iOS 27（移动端 `< 768px`） |
| :--- | :--- | :--- |
| **圆角形态** | 全尺寸统一默认全圆角胶囊（`rounded-full`），需要直角或小圆角时直接通过 Tailwind `className` 覆盖（如 `rounded-md`） | 全尺寸统一全圆角胶囊（`rounded-full`），贴合指尖触控 |
| **尺寸比例** | 紧凑桌面密度（`default`: `32px` / `13.5px`、`icon`: `32px`） | Apple HIG 触控人体工学（`default`: `46px` / `17px`、`lg`: `50px`、`icon`: `44px`） |
| **光学曲面** | 适度桌面折边（`bezel: 11`, `refraction: 46`） | 更丰满的移动端液态曲率（`bezel: 14`, `refraction: 56`） |
| **Motion 弹簧** | 轻快桌面按压（`scale: 0.97`, `stiffness: 520`） | Q 弹液态回弹（`scale: 0.935`, `stiffness: 380, damping: 22`） |

## 使用方式

```tsx
import { Button } from '@/components/ui/button';

export function Example() {
  return (
    <div className="flex items-center gap-3">
      <Button glass>立即体验</Button>
      <Button variant="secondary" glass>了解更多</Button>
      <Button variant="destructive" glass>删除项目</Button>
      <Button variant="secondary" glass glassProps={{ frost: 0.12, dispersion: 0.08 }}>
        自定义色散折射
      </Button>
    </div>
  );
}
```

## Props API

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `variant` | `'default' \| 'secondary' \| 'outline' \| 'ghost' \| 'destructive' \| 'link'` | `'default'` | 标准 shadcn 语义变体 |
| `glass` | `boolean` | `false` | 开启 Apple Liquid Glass 光学折射材质（自动按语义适配蓝/白/红玻璃，并联动全局通透度） |
| `size` | `'xs' \| 'sm' \| 'default' \| 'lg' \| 'icon-xs' \| 'icon-sm' \| 'icon' \| 'icon-lg'` | `'default'` | 响应式尺寸阶梯（移动端自动匹配 iOS 27，桌面端自动匹配 macOS 27） |
| `surface` | `'content' \| 'over-glass'` | `'content'` | 按钮所处表面语境（对照 macOS 27 Content Area 与 Over-glass 规范） |
| `glassProps` | `Pick<LiquiGlassProps, 'material' \| 'profile' \| 'finish' \| 'frost' \| 'refraction' \| 'bezel' \| 'blur' \| 'dispersion' \| 'specular' \| 'saturation' \| 'elevated'>` | — | 透传给 `@liqui-design/glass` 的光学微调参数（仅 `glass={true}` 时生效） |
| `disableMotion` | `boolean` | `false` | 禁用 Motion 弹簧按压动画（自动遵循系统 `prefers-reduced-motion`） |
| `render` | `React.ReactElement` | — | 继承自 `@base-ui/react/button`，支持自定义渲染元素（如 Next.js `<Link />`） |
