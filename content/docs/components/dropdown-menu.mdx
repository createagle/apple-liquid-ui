完全兼容 shadcn/ui 标准 JSX API（`<DropdownMenu>` / `<DropdownMenuTrigger>` / `<DropdownMenuContent>` / `<DropdownMenuGroup>` / `<DropdownMenuItem>` / `<DropdownMenuCheckboxItem>` / `<DropdownMenuRadioGroup>` / `<DropdownMenuSub>`），无需手写双端判断，通过 `useIsMobile()`（`768px`）自动按设备形态切换交互容器：

- **桌面端（`>= 768px` · macOS 27）**：基于 `@base-ui/react/menu` 展开 `14px` 圆角悬浮液态玻璃菜单，具备 `28px` 紧凑行高、`#0069F9` 经典蓝色悬停高亮、右侧勾选态（`✓`）、快捷键提示与向右侧展开的子菜单。
- **移动端（`< 768px` · iOS 27）**：自动切换为基于 `@base-ui/react/drawer` 的**顶部 `32px` 大圆角 iOS 27 底部液态玻璃 Drawer**，支持手势下滑关闭、顶部拖拽手柄、分组卡片列表（Inset Grouped List）与右侧 Apple Blue 勾选态；点击子菜单时在 Drawer 内平滑切入二级视图并在顶部提供 `‹ 返回` 导航栏。

## 安装（Shadcn Registry）

```bash
# 通过配置好的 @apple-liquid 命名空间安装（自动关联 drawer、liquid-surface、use-mobile 与 liquid-glass）
npx shadcn@latest add @apple-liquid/dropdown-menu

# 或直接通过 URL 安装
npx shadcn@latest add https://your-domain.com/r/dropdown-menu.json
```

## 使用方式

```tsx
import { Button } from '@/components/ui/button';
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuGroup,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuShortcut,
  DropdownMenuTrigger,
} from '@/components/ui/dropdown-menu';

export function Example() {
  return (
    <DropdownMenu>
      <DropdownMenuTrigger render={<Button variant="secondary">操作菜单</Button>} />
      <DropdownMenuContent title="文件操作" className="w-56">
        <DropdownMenuGroup>
          <DropdownMenuLabel>文件</DropdownMenuLabel>
          <DropdownMenuItem>
            重命名
            <DropdownMenuShortcut>⌘E</DropdownMenuShortcut>
          </DropdownMenuItem>
          <DropdownMenuItem>
            制作副本
            <DropdownMenuShortcut>⌘D</DropdownMenuShortcut>
          </DropdownMenuItem>
        </DropdownMenuGroup>
        <DropdownMenuSeparator />
        <DropdownMenuItem variant="destructive">
          移到废纸篓
          <DropdownMenuShortcut>⌘⌫</DropdownMenuShortcut>
        </DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  );
}
```

> **提示**：Base UI 要求 `DropdownMenuLabel` 必须嵌套在 `<DropdownMenuGroup>` 内部使用，以便在桌面端无障碍读屏器与移动端分组卡片（Inset Grouped List）中正确关联标题。

## Props API

### `DropdownMenuContent`

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `title` | `React.ReactNode` | — | 移动端底部 Drawer 顶部居中的主标题（进入子菜单后会自动替换为子菜单名称与返回键） |
| `side` | `'top' \| 'bottom' \| 'left' \| 'right'` | `'bottom'` | 仅桌面端：相对触发器的弹出方向 |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` | 仅桌面端：沿弹出轴线的对齐方式 |
| `sideOffset` | `number` | `6` | 仅桌面端：与触发器之间的间距（px） |
| `alignOffset` | `number` | `0` | 仅桌面端：沿对齐方向的偏移量（px） |

### `DropdownMenuItem`

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `variant` | `'default' \| 'destructive'` | `'default'` | `destructive` 呈现 Apple Red 危险操作语义 |
| `inset` | `boolean` | `false` | 左侧额外留白以对齐带有前导图标的菜单项 |
| `closeOnClick` | `boolean` | `true` | 点击后是否自动关闭菜单 / 底部 Drawer |
| `disabled` | `boolean` | `false` | 禁用菜单项交互 |

### `DropdownMenuSubContent`

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `side` | `'top' \| 'bottom' \| 'left' \| 'right'` | `'right'` | 仅桌面端：子菜单弹出方向（移动端会自动转为 Drawer 内二级视图与返回栏） |
| `sideOffset` | `number` | `4` | 仅桌面端：与父级菜单之间的间距（px） |
