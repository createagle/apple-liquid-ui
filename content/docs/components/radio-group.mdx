完全兼容 shadcn/ui 标准 JSX API（`<RadioGroup>` / `<RadioGroupItem>`），采用纯视口断点（`md:` / `768px`）实现双端尺寸自适应：

- **桌面端（`>= 768px` · macOS 27）**：对齐 macOS 27 UI Kit `3 Rg` 规范，`16×16` 圆形单选框配 `6px` 白色立体高光内圆点与 Apple Blue 液态光泽底。
- **移动端（`< 768px` · iOS 27）**：自动放大至 `22×22` 圆形触控尺寸并扩展点击热区，适合在设置面板与表单列表中单手切换。
- **组级属性透传**：直接在 `<RadioGroup>` 上设置 `size`、`glass` 或 `disableMotion`，子级所有 `<RadioGroupItem>` 将自动继承，也可按需在单个选项上覆盖。

## 液态玻璃材质（Glass）

在 `<RadioGroup glass>` 上开启正交液态玻璃表面，未选中圆环实时响应全局「玻璃通透度」滑块，选中态则始终保持高对比度：

## 使用方式

```tsx
import { RadioGroup, RadioGroupItem } from '@/components/ui/radio-group';

export function Example() {
  return (
    <RadioGroup defaultValue="contacts">
      <label className="flex items-center gap-2.5">
        <RadioGroupItem value="contacts" />
        <span className="text-sm">仅限联系人</span>
      </label>
      <label className="flex items-center gap-2.5">
        <RadioGroupItem value="everyone" />
        <span className="text-sm">所有人</span>
      </label>
    </RadioGroup>
  );
}
```

## Props API

### `RadioGroup`

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `size` | `'sm' \| 'default' \| 'lg'` | `'default'` | 透传给子项的默认尺寸（移动 `18/22/26px` ↔ 桌面 `14/16/20px`） |
| `glass` | `boolean` | `false` | 透传给子项的正交液态玻璃表面开关 |
| `disableMotion` | `boolean` | `false` | 禁用子项选中内圆点的弹簧缩放动效 |

### `RadioGroupItem`

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `size` | `'sm' \| 'default' \| 'lg'` | 继承自 `RadioGroup` | 单独覆盖当前单选项的尺寸 |
| `glass` | `boolean` | 继承自 `RadioGroup` | 单独覆盖当前单选项的玻璃材质 |
| `disableMotion` | `boolean` | 继承自 `RadioGroup` | 单独覆盖当前单选项的动效开关 |
