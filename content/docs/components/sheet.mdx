基于 `@base-ui/react/dialog` 实现，完全兼容 shadcn/ui 标准 JSX API（`<Sheet>` / `<SheetTrigger>` / `<SheetContent>` / `<SheetHeader>` / `<SheetFooter>` / `<SheetTitle>` / `<SheetDescription>` / `<SheetClose>`）：

- **桌面端（`>= 768px` · macOS 27）**：四周保留 `12px` 悬浮边距，以 `26px` 圆角液态玻璃面板浮于内容之上，还原 macOS 27 检查器（Inspector）的通透层次。
- **移动端（`< 768px` · iOS 27）**：自动贴边停靠并切换为 `28px` / `32px` 大圆角与安全区底部留白，触控与阅读空间更充裕。

## 响应式实时预览

在面板中直接嵌入 `Input`（`surface="over-glass"`）、`Slider` 与 `Switch`；点击右上角切换 **桌面 / 平板 / 移动端** 查看悬浮与贴边形态切换：

## 安装（Shadcn Registry）

```bash
# 通过配置好的 @apple-liquid 命名空间安装（自动关联 liquid-surface 与 liquid-glass）
npx shadcn@latest add @apple-liquid/sheet
```

## Props API

### `SheetContent`

| 属性 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `side` | `'right' \| 'left' \| 'top' \| 'bottom'` | `'right'` | 面板滑入方向 |
| `glass` | `boolean` | `true` | 是否启用 Apple 27 液态玻璃折射表面 |
| `showCloseButton` | `boolean` | `true` | 是否在右上角显示圆形关闭按钮 |
